# 🛟 拼拼救援队：游戏设计

> 状态：设计已定，待开发。这份文档是开发依据，玩法或数值要改就直接改这里。

## 1. 一句话

黄熊队长用磁力零件拼一台救援载具（车、船、飞机，或者它们的混合），出发穿过陆地或海洋，
顶住海啸、台风、龙卷风或地震，把困住的好朋友救回来。

灵感来自孩子手上的一套磁力变形工程车：车头、中间段、车尾都能拆开，前后随意组合。
和「海啸来啦」一样，每种灾害对应一个真实的物理道理（那边是「楼高挡浪」「阻尼球抗震」），
而且**总有不止一种解法**，让孩子自己摸索什么样的载具才结实。

## 2. 设计原则

1. **不用认字**：所有提示都是语音和图标。
2. **没有万能的载具**：每个属性都有代价，每一关都要重新想。
3. **每条规则看得见，并且能用一句话说清楚**。
4. **失败要好笑，不能吓人**：车翻了，黄熊喊一声「哇哦～」；没有受伤的画面。
5. **启发，不直接给答案**：提示逐级加强（见第 8 节）。
6. **连到实体玩具**：成功后提示「用你的磁力车也拼一台吧！」

- 救回来的朋友出现在基地的「好朋友墙」上。

## 4. 载具：头 ＋ 4×4 中间区 ＋ 尾

### 4.1 拼装网格

从上往下看，载具朝右开（和路线前进的方向一致）：

```
        尾列   ←── 中间区 4×4 ──→   头列
行 1    [T]   [ ] [ ] [ ] [ ]     [H]
行 2    [T]   [ ] [ ] [ ] [ ]     [H]
行 3    [T]   [ ] [ ] [ ] [ ]     [H]
行 4    [T]   [ ] [ ] [ ] [ ]     [H]
```

- 一共 6 列（长）× 4 行（宽）。
- **头只能放在最右列，尾只能放在最左列，中间段只能放在中间 4×4 区。**
- **必须至少有一个头和一个尾**；中间区不用放满，一块都不放也可以（头直接接尾）。
- 所有块必须连成一体（上下左右相邻才算连上），所以 T 形、L 形这些形状都可以。
- 头可以放好几个，每个头是一个座位。
- 不满足条件时「出发」按钮是灰的；点它的话，语音会说缺什么：「还要一个车头哦」「还要一个车尾哦」「这块没有吸上哦」。

### 4.2 操作

- 底部是零件盘，分三栏：头、中间段、尾。
- **点一下格子放一块**；**手指划过几个格子，就一次铺上一排同样的段**（沿用海啸游戏划墙的手势）。
- 换一种块直接覆盖；拖到垃圾桶或者用 🧹 拆掉；「清空」要连按两次。
- 右上角有一个可以转动的 3D 小预览。吸上时咔嗒一声，冒出一点磁力火花。

### 4.3 零件表（数值是初稿，开发时再调）

单位：重量 1 = 一块轻的段；高度以一块的高度为 1；浮力和升力的单位和重量一样（浮力 ≥ 重量才浮得起来）。

**头**（每个都自带底部）

| -------- | ---- | ---- | ---- | ----------------------- |
| 卡车头   | 轮子 | 2    | 2    | 普通                    |

| 火车头   | 轮子 | 3    | 2    | 尖头破浪：浪的冲力 ×0.7 |
| 船头     | 船底 | 1    | 1    | 浮力 3                  |
| 直升机头 | 滑橇 | 1    | 1.5  | 轻                      |

| 滚筒段   | 滚筒（算轮子） | 4                    | 1                    | 特别重，抓地 2             |
| 船体段   | 船底           | 1                    | 1                    | 浮力 3                     |

| 火车尾     | 轮子 | 2    | 重                                      |
| 船尾       | 船底 | 1    | 浮力 2                                  |
| 直升机尾翼 | 滑橇 | 0.5  | 飞的时候不打转（龙卷风里升力影响 ×0.8） |

### 4.4 汇总属性（`vehicle.ts` 里的纯函数）

| 属性       | 算法                                     |
| ---------- | ---------------------------------------- |
| 总重 W     | 所有块的重量相加                         |
| 长 L、宽 B | 占用的列数、行数                         |
| 重心       | 按重量加权的平均位置，高度方向也算       |
| 偏心       | 重心离中线的横向距离，用来算「左右平衡」 |
| 侧面积     | 每一列最高那块的高度相加（侧风吹到的面） |
| 顶面积     | 块数（龙卷风往上吸的面）                 |
| 能在陆地走 | 有任何一块轮子或滚筒                     |
| 能在水上漂 | 浮力总和 ≥ W                             |
| 能飞       | 升力总和 ≥ W（能飞就一定飞）             |
| 锚         | 铲斗和吊钩的锚力相加                     |
| 够得到高处 | 有吊臂段                                 |

### 4.5 自动起名

按下面的顺序判断，语音报出「你拼了一台 ××！」：

1. 能飞，又有船底和轮子 → 全能救援机
2. 能飞，又有船底 → 会飞的船
3. 能飞，又有轮子 → 飞天车
4. 能飞 → 直升机
5. 有船底，又有轮子 → 水陆两用车
6. 只有船底 → 船
7. 只有轮子：按最显眼的段起名（吊车、挖掘车、搅拌车、压路机、自卸车、火车），都没有就叫小汽车

## 5. 地形

路线横向卷动，载具自动从左开到右，把朋友接上再开回基地。

| 地形    | 路线                   | 能过去的载具     |
| ------- | ---------------------- | ---------------- |
| 🌾 陆地 | 全是地面；地震时会裂开 | 车、飞机         |
| 🌊 海洋 | 全是水                 | 船、飞机         |
| 🏖️ 海岸 | 陆地 → 海 → 陆地       | 水陆两用车、飞机 |

开不过去的时候，载具会停在边上：只有轮子的车停在岸边（「过不去呀～」），船在陆地上原地挪动，
浮力不够的会慢慢沉下去，再被救生气球托回来（不吓人）。

## 6. 灾害和计算

灾害在路线中间发生，持续 10–15 秒。屏幕上方显示**拔河条**：🌀 灾害的力气对 🚗 载具的力气。
比值 r = 灾害力气 ÷ 载具力气：

- r < 0.7：⭐⭐⭐ 稳稳的
- 0.7 ≤ r < 1：⭐⭐ 晃晃悠悠，但过去了
- r ≥ 1：失败

| 灾害      | 灾害的力气                                               | 载具的力气         | 补充                                                                            |
| --------- | -------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------- |
| 🌀 台风   | 风力 × 侧面积 × 平均高度 / 2（翻倒力矩），流线型车头打折 | W × (B / 2 − 偏心) | 能飞的直接被吹走；吊臂举高时高度按 4 算                                         |
| 🌪️ 龙卷风 | 强度 × 顶面积                                            | W + 锚             | 能飞的直接被卷走；失败时在天上转几圈再轻轻落下                                  |
| 🫨 地震   | 晃动幅度 × 重心高度 / B，有阻尼球再 ×0.4                 | 固定的承受值       | 另有裂缝宽 c 格：长度 L ≤ c 会掉进去，能飞的不受影响                            |
| 🌊 海啸   | 浪高 × 侧面积，尖头打折                                  | W × 摩擦           | 能飞的安全；浮在水上的会越过浪（B = 1 的窄船算 ⭐⭐）；在陆地上车顶比浪高就安全 |

- 在水上遇到台风时，用同一个翻倒公式，所以**宽的船不容易翻**。
- **左右平衡**：偏心会让载具看起来歪着，船会侧倾，飞机会斜。对结果的影响只在台风公式里，比较轻。
- 每种灾害分小、中、大三档强度；第一版关卡里写死每关用哪一档。

## 8. 启发和奖励

**三级提示**（同一关、同一个失败原因连续出现时逐级往上加）：

1. 只说发生了什么：「车被风吹倒了！」
2. 问一个生活里的问题：「风能吹动小树叶，能吹动大石头吗？」
3. 零件盘里有帮助的零件轻轻闪光。

**成功**：说出原理，比如「又矮又重，风就吹不倒啦！」，并奖励一张原理贴纸。

| 贴纸      | 原理                           |
| --------- | ------------------------------ |
| 🛞 轮子   | 有轮子才能在地上跑             |
| 🛟 船底   | 有船底才能在水上漂             |
| 🚁 升力   | 螺旋桨够多才能飞，越重要的越多 |
| 🪨 重     | 越重越不怕风                   |
| 📏 矮     | 越矮越稳                       |
| ⚓ 抓地   | 铲斗和吊钩能抓住地面           |
| 🚂 长     | 长车能跨过裂缝                 |
| ↔️ 宽     | 宽的不容易翻                   |
| ⚖️ 平衡   | 左右要平衡                     |
| 🟡 阻尼球 | 阻尼球不怕摇                   |

## 9. 一局的流程

1. **📜 任务卡**：路线预览、灾害图标、等着被救的朋友，配语音。
2. **🔧 拼装**：拼好按「出发！」；车库记住最近拼的 6 台。
3. **🚀 出发**：自动前进，镜头切到 3/4 斜侧视角，灾害来时出现拔河条。
4. **🐾 救援**：到了朋友那里，需要吊臂的就把吊臂举起来（动画），朋友坐上车。
5. **🏁 结果**：⭐ 和贴纸；失败就按提示改一改，按「再改一改」回到拼装，载具保持原样。

## 11. 技术方案

- 路由 `rescue`，在 `src/app/games.ts` 里注册，懒加载。
- 视角：拼装用从上往下的 2D 网格加 3D 小预览；出发后是 three.js 3/4 斜侧视角，横向卷动。

```
src/app/games/rescue/
  rescue.ts / .html / .scss   组件和状态机：任务 → 拼装 → 出发 → 结果
  rescue-data.ts              关卡、台词、贴纸
  parts.ts                    零件定义和数值（第 4.3 节）
  vehicle.ts                  网格模型、合法性检查、汇总属性、起名（纯函数）
  sim.ts                      地形 × 灾害 → 结果、失败原因、动画时间线（纯函数）
  sim.spec.ts                 关卡的「好的解法」都能过、典型错误都会失败
  models.ts                   零件和角色的 three.js 模型
  scene.ts                    路线场景、水面、镜头
  disasters/                  风、龙卷风、地震；海浪复用 tsunami/wave-mesh.ts
```

- `vehicle.ts` 和 `sim.ts` 不碰 three.js，可以单独测试；调数值时先让第 7 节的每一关都能用表里的解法通过。
- 存档（localStorage，读写都包 try/catch）：`rescue.progress` 存星星、贴纸和救过的朋友；`rescue.garage` 存最近 6 台载具。

## 12. 开发顺序

1. **M1 拼装**：网格、零件、合法性、3D 预览、起名。第 1、2 关可以玩通（不含灾害）。
2. **M2 灾害**：`sim.ts` 和测试、三种地形、四种灾害、第 3–10 关。
3. **M3 打磨**：三级提示、贴纸册、好朋友墙、自由模式、语音生成、README 截图。
