# 🛟 拼拼救援队：游戏设计

> 状态：第一版已实现（`src/app/games/rescue/`）。玩法或数值要改，先改这里，再改代码和 `rescue.spec.ts`。

## 1. 一句话

黄熊队长用磁力零件拼一台救援载具（车、船、飞机，或者它们的混合），出发穿过陆地或海洋，
顶住海啸、台风、龙卷风、地震或漩涡，把困住的好朋友救回来。

灵感来自孩子手上的一套磁力变形工程车：车头、中间段、车尾都能拆开，前后随意组合。
和「海啸来啦」一样，每种灾害对应一个真实的物理道理（那边是「楼高挡浪」「阻尼球抗震」），
而且**总有不止一种解法**，让孩子自己摸索什么样的载具才结实。

## 2. 设计原则

1. **不用认字**：所有提示都是语音和图标。
2. **没有万能的载具**：每个属性都有代价，每一关都要重新想。
3. **每条规则看得见，并且能用一句话说清楚**。
4. **失败要好笑，不能吓人**：车翻了，黄熊喊一声「哇哦～」；没有受伤的画面。
5. **启发，不直接给答案**：提示逐级加强（见第 8 节）。
6. **连到实体玩具**：成功后提示「用你的磁力车也拼一台吧！」

## 3. 角色

| 角色        | 造型                                                 | 作用                       |
| ----------- | ---------------------------------------------------- | -------------------------- |
| 🐻 黄熊队长 | 黄色的熊，白肚子，灰鼻子（和白熊玩偶同款，换成黄色） | 主角，每一局都坐在车头驾驶 |
| 🐨 考拉     | 灰色，大黑鼻子，白肚子                               | 待救援：抱在树上、在小岛上 |

- 模型全部用球体程序化生成，软软圆圆的，和玩偶风格一致，不需要外部模型文件。
- 救回来的朋友出现在关卡地图上的「好朋友墙」上，记着每个朋友救了几次。

## 4. 载具：6×4 的拼装网格

### 4.1 拼装规则

从上往下看，载具朝右开（和路线前进的方向一致）。一共 6 列（长）× 4 行（宽），**任何格子都能放任何零件**，规则只有这几条：

- **必须至少有一个车头和一个车尾。**
- **所有块要连成一体**（上下左右挨着才算吸上），T 形、L 形都可以。块数最多的那一坨算车，其他的都算「没吸上」。
- **车头前面（右边）不能再接东西，车尾后面（左边）不能再接东西**：玩具的车头只有后面有磁铁，车尾只有前面有。上下挨着的车头、车尾没关系。
- 中间段不用放满，车头可以直接接车尾。网格四周空着的行和列不算长宽。
- 车头可以放好几个；黄熊队长坐在最靠中间的那个上。

> 原本设计成「头只能放最右列、尾只能放最左列」，再把空着的列吸拢。实现时发现吸拢会让别的行凭空断开（`rescue.spec.ts` 里有例子），改成现在的规则：更自由，也更像真的磁力玩具。

不符合规则时「出发」按钮是灰的；点它，出问题的格子闪红，同时读出原因：

| 问题             | 语音                     |
| ---------------- | ------------------------ |
| 什么都没放       | 先拼一台车吧！           |
| 没有车头         | 还要一个车头哦！         |
| 没有车尾         | 还要一个车尾哦！         |
| 有块没吸上       | 有一块没有吸上哦！       |
| 车头前面接了东西 | 车头前面不能再接东西哦！ |
| 车尾后面接了东西 | 车尾后面不能再接东西哦！ |

### 4.2 操作

- 底部是木头零件盘，两排：上排是车头（橙底）和车尾（蓝底），下排是 9 种中间段、🧹 拆掉、🗑️ 全部拆掉（连按两次）。点零件会读出它的名字。
- **点一下格子放一块**；**手指划过几个格子，一次铺上一排同样的**（和海啸来啦划墙一样）。放上去「咔嗒」一声，越下面的行音越高。
- 已经放好的**自卸斗，再用自卸斗点一下：装上石头**（重量 1 → 3），再点一下倒掉。
- 右边是木头转台：拼好的车放在上面慢慢转，手指拖动可以转着看；新吸上的块从上面落下来弹一下；车上方显示它叫什么。
- **车库**：每次出发，把这台车拍一张小图存进车库（一样的车只存一台），最多 6 台，点一下就开出来。
- 零件盘里的小图是启动时用 three.js 把每个零件现画出来的。

### 4.4 汇总属性（`vehicle.ts` 里的纯函数）

| 属性       | 算法                                                      |
| ---------- | --------------------------------------------------------- |
| 总重 W     | 所有块的重量相加                                          |
| 长 L、宽 B | 占用的列数、行数（去掉四周空着的）                        |
| 块数       | 龙卷风往上吸的面                                          |
| 侧面积 A   | 每一列最高那块的高度相加（侧风吹到的面）；吊臂举着按 4 算 |
| 最高       | 最高那块的高度                                            |
| 重心高     | 每块重量 × 半个高度，加权平均                             |
| 偏心       | 重心离车宽中线的距离（格），用来算「左右平衡」            |
| 能在地上跑 | 有任何一块轮子或滚筒                                      |
| 浮得起来   | 浮力总和 ≥ W（有没有船底另算）                            |
| 能飞       | 有螺旋桨，并且升力总和 ≥ W。**能飞就一定飞**              |
| 锚         | 铲斗和吊钩的锚力相加（只在地上有用）                      |
| 够得到高处 | 有吊车                                                    |

有螺旋桨但飞不起来时，出发时螺旋桨拼命转、车蹦两下，读「太重了，飞不起来！」，然后照常开。

### 4.5 自动起名

按下面的顺序判断，出发时读「你拼了一台 ××！」：

1. 能飞，又有船底和轮子 → 全能救援机
2. 能飞，又有船底 → 会飞的船
3. 能飞，又有轮子 → 飞天车
4. 能飞 → 直升机
5. 有船底，又有轮子 → 水陆两用车
6. 只有船底 → 船
7. 既没轮子也没船底（螺旋桨不够） → 小飞机
8. 只有轮子：按最显眼的段起名（吊车、挖掘车、搅拌车、压路机、自卸车、火车），都没有就叫小汽车

## 5. 地形

路线横向卷动，载具自动从左开到右，接上朋友就算成功。

| 地形    | 路线                   | 能过去的载具     |
| ------- | ---------------------- | ---------------- |
| 🌾 陆地 | 全是地面；地震时会裂开 | 车、飞机         |
| 🌊 海洋 | 全是水                 | 船、飞机         |
| 🏖️ 海岸 | 陆地 → 海 → 陆地       | 水陆两用车、飞机 |

海洋关从码头出发，船从码头滑进水里。开不过去的时候：只有轮子的车停在岸边（「过不去呀～」）；
船在陆地上原地扭来扭去；浮力不够的咕噜咕噜沉下去一半，黄熊跳上旁边的救生圈（不吓人）。

## 6. 灾害和计算

结果全部由 `sim.ts` 的 `simulate(载具, 关卡)` 算出来（纯函数），场景只负责把它演出来。顺序是：

1. **一路过去**：能飞的哪里都能去。不能飞的：地上要有轮子，否则「在地上走不动」；水上要有船底，否则「过不了水」；有船底但浮力不够就「沉了」。
2. **够不够得着**：朋友在树上、屋顶上，要有吊车（或者能飞），否则「够不着」。够得着的话先把吊臂举起来，**灾害就在举着吊臂的时候来**。
3. **灾害**：算出比值 r = 灾害的力气 ÷ 载具的力气。r < 0.7 是 ⭐⭐⭐ 稳稳的；0.7 ≤ r < 1 是 ⭐⭐ 晃晃悠悠；r ≥ 1 失败。

| 灾害      | 灾害的力气                                                                            | 载具的力气                  | 补充                                                     |
| --------- | ------------------------------------------------------------------------------------- | --------------------------- | -------------------------------------------------------- |
| ⛈️ 台风   | P × A × (A / L) / 2（翻倒力矩：侧面越大、越高越吃风）                                 | W × max(0.15, B / 2 − 偏心) | 能飞的直接被吹走；在水上用同一个公式，所以宽的船不容易翻 |
| 🌪️ 龙卷风 | P × 块数                                                                              | W + 锚（水上没有锚）        | 能飞的直接被卷走                                         |
| 🫨 地震   | P × 重心高 / B，有阻尼球再 ×0.4                                                       | 1                           | 有裂缝时，车长 L ≤ 裂缝宽就掉进去；能飞的不受影响        |
| 🌊 海啸   | 在水上：B = 1 的窄船 0.8，宽的 0.3（一定过得去）；在地上：P × B × 最高 × (火车头 0.7) | 在地上：W                   | 能飞的不受影响                                           |
| 🌀 漩涡   | P                                                                                     | L + 0.2 × W                 | 只在水上；能飞的不受影响。船越长越横得住                 |

每一档的力气 P（`POWER`，第 1、2、3 档）：

| 灾害           | 1   | 2   | 3   |
| -------------- | --- | --- | --- |
| 台风           | 1   | 2   | 3   |
| 龙卷风         | 1   | 2   | 2.6 |
| 地震           | 1   | 1.6 | 2.4 |
| 海啸（在地上） | 0.6 | 1   | 1.4 |
| 漩涡           | 3   | 4.2 | 5.4 |

- **左右平衡**：偏心只出现在台风公式里，影响比较轻。
- 灾害来时屏幕上方有**拔河条**：左边是灾害，右边是黄熊队长，绳结的位置是 1 / (1 + r)。r 越大绳结越往左（灾害那边）跑；红、黄、绿三段对应失败、两星、三星。

- 任务卡和拼装页上标出朋友在哪（🌳 树上、🏠 屋顶上、🧊 冰山上……），灾害越强图标越大。
- **自由模式**（🎲）：随机抽地形、灾害（海上不会地震，海边只有台风、海啸和漩涡；漩涡只在水上）、强度和朋友；陆地上三成多的机会朋友在树上或屋顶上。可以再抽。海上的龙卷风只有第 1 档：船抓不住地，再强就拼不出能过的船了。`rescue.spec.ts` 会把自由模式能抽到的每一种组合都跑一遍，确认至少有一种拼法能过。
- 第二期：雪山（暴雪、雪崩）、火山岛、沙漠（沙尘暴）；窄桥和窄峡谷（太宽过不去，让「宽」也有代价）；
  开着自己拼的载具进「海啸来啦」的小岛救小人。

## 8. 启发和奖励

**三级提示**（同一关、同一个失败原因连续出现时逐级往上加，这一关成功后清零）：

1. 只说发生了什么：「车被风吹倒了！」（演出里说）
2. 结果卡出来时问一个生活里的问题：「风能吹动小树叶，能吹动大石头吗？」
3. 结果卡上出现 💡 和建议的零件小图；回到拼装时，零件盘里这几个零件跳动发光。

**成功**：撒彩带，读「谢谢黄熊队长！」，再说出这次用上的道理，奖励一张还没有的原理贴纸。
贴纸按这次的情况挑最贴切的、还没得到的那张（`principles()`）：比如龙卷风里用铲斗抓住地面给 ⚓，海上台风里用宽船给 ↔️。
所有贴纸都有了就不再给，三星时读「用你的磁力车也拼一台吧！」。

| 贴纸      | 原理                     |
| --------- | ------------------------ |
| 🛞 轮子   | 有轮子，就能在地上跑！   |
| 🛟 船底   | 有船底，就能浮在水上！   |
| 🚁 升力   | 螺旋桨够多，就能飞起来！ |
| 🪨 重     | 又重又稳，吹不动！       |
| 📏 矮     | 矮矮的，风就吹不倒！     |
| ⚓ 抓地   | 抓住地面，就卷不走！     |
| 🚂 长     | 车子长长的，跨过了裂缝！ |
| ↔️ 宽     | 站得宽宽的，就不会翻！   |
| ⚖️ 平衡   | 左右一样重，稳稳的！     |
| 🟡 阻尼球 | 阻尼球不怕摇！           |

贴纸本（📒）里点一张已有的贴纸，会再读一遍它的道理。

## 9. 一局的流程

1. **🗺️ 地图**：10 关、好朋友墙、🎲 自由模式、📒 贴纸本。
2. **📜 任务卡**：地形 ＋ 灾害 → 朋友（在哪），配语音；背后已经是这一关的场景。
3. **🔧 拼装**：拼好按 🚀。
4. **🚀 出发**：读出车名，黄熊喊「黄熊队长，出发！」，镜头跟着车走，灾害来时出现拔河条。
5. **🐾 救援**：到了朋友那里，需要的话把吊臂举起来、伸长；朋友跳上车，「救到啦！」
6. **🏁 结果卡**：⭐ 和贴纸，或者 😵 加提示。按钮：🗺️ 回地图、🔁 原样再来一次、🔧 再改一改（回到拼装，车保持原样）、▶ 下一关。

## 11. 技术方案

- 路由 `rescue`，在 `src/app/games.ts` 里注册，懒加载。
- 视角：拼装用 HTML 网格加 three.js 小转台；出发后是 three.js 透视镜头，从右前上方斜着看，跟着载具走。

```
src/app/games/rescue/
  rescue.ts / .html / .scss   组件和流程：地图 → 任务卡 → 拼装 → 出发 → 结果；存档、提示、车库
  rescue-data.ts              关卡、朋友、台词、贴纸、失败原因和提示
  parts.ts                    零件和数值（第 4.3 节）
  vehicle.ts                  网格、拼装规则、汇总属性、起名（纯函数）
  sim.ts                      载具 × 关卡 → 结果、失败原因、比值（纯函数）
  rescue.spec.ts              规则测试：npm run test:rescue
  models.ts                   零件和玩偶的 three.js 模型
  preview.ts                  拼装页的转台、零件小图、车库小图
  journey.ts                  出发后的场景、地形、四种灾害的演出（海浪复用 tsunami/wave-mesh.ts）
```

- `vehicle.ts` 和 `sim.ts` 不碰 three.js，可以直接用 `tsx --test` 跑测试。
- 存档：localStorage 的 `kids-games.rescue.v1`（读写都包 try/catch），存每关星星、贴纸、每个朋友救了几次、上一次拼的车和车库。
- 开发模式下 `window.rescue`（组件）和 `window.rescueJourney`（场景）给测试脚本用；`rescueJourney.timeScale = 3` 让动画快一点。
